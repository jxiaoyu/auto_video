# Auto Video Pipeline — Design Spec

**Date:** 2026-05-27  
**Status:** Approved

---

## Overview

A Python CLI tool that fully automates the production of short English-conversation videos.
The user provides a topic; the tool outputs a ready-to-use vertical MP4 (~1 minute).

**Entry point:**
```bash
python make_video.py --topic "职场催进度"
```

---

## Pipeline

Five sequential steps. Each step writes its output to disk before the next step begins.
Re-running the command skips any step whose output files already exist, so a failed run
can be resumed without redoing earlier (and costly) steps.

```
Step 1  Gemini API   →  script.json        structured dialogue + illustration prompts
Step 2  Gemini API   →  round_N.png        one cartoon illustration per round
Step 3  Google TTS   →  line_N_M.mp3       one audio clip per dialogue line
Step 4  FFmpeg       →  segments/          one video segment per line (image + audio + subtitle)
Step 5  FFmpeg       →  final.mp4          concatenated final video
```

**Selective redo:**
```bash
python make_video.py --topic "职场催进度" --redo images
```
Supported redo targets: `script`, `images`, `audio`, `video`.

---

## Dialogue Structure

A "round" is one full exchange: Speaker A says something, Speaker B responds.
One illustration is generated per round and shown throughout both lines of that round.

A ~1-minute video contains approximately 3–5 rounds (6–10 lines total).

### script.json schema

```json
{
  "topic": "string",
  "rounds": [
    {
      "round": 1,
      "illustration_prompt": "English prompt for Gemini image generation",
      "lines": [
        { "speaker": "A", "text": "..." },
        { "speaker": "B", "text": "..." }
      ]
    }
  ]
}
```

`illustration_prompt` is generated by Gemini together with the dialogue in a single API call,
so no extra call is needed for prompting.

## Tech Stack

| Concern           | Tool                                      |
|-------------------|-------------------------------------------|
| Dialogue + prompts| Gemini API (`gemini-2.0-flash`)           |
| Image generation  | Gemini API (`imagen-3.0-generate`)        |
| Text-to-speech    | Google Cloud Text-to-Speech               |
| Video assembly    | FFmpeg (subprocess calls)                 |
| Subtitle rendering| FFmpeg `drawtext` filter                  |
| Language          | Python 3.10+                              |

**System dependency:** `ffmpeg` must be installed (`brew install ffmpeg`).

**Default voices:**
- Speaker A: `en-US-Journey-F` (female)
- Speaker B: `en-US-Journey-D` (male)

Voices are configurable in `config.py`.

---

## Video Format

- Resolution: 1080 × 1920 (vertical 9:16)
- Illustration: fills the frame
- Subtitles: white text with dark outline, centered at bottom
- Each segment duration equals the TTS audio duration for that line

## Project Structure

```
auto_video/
├── make_video.py           # entry point; orchestrates all steps
├── config.py               # API keys, voice names, video dimensions
├── steps/
│   ├── generate_script.py  # Step 1: Gemini dialogue + prompts
│   ├── generate_images.py  # Step 2: Gemini image generation
│   ├── generate_audio.py   # Step 3: Google Cloud TTS
│   └── assemble_video.py   # Steps 4–5: FFmpeg assembly
├── output/
│   └── {topic}/
│       ├── script.json
│       ├── round_1.png
│       ├── line_1_1.mp3
│       ├── segments/
│       └── final.mp4
└── requirements.txt
```

---

## Error Handling

- API failure: print the step name, error message, and the output path being written to
- Missing dependencies: check for `ffmpeg` on startup and fail fast with install instructions
- Partial output: any incomplete output file is deleted before retrying, to avoid corrupt state

---

## Out of Scope

- Publishing / uploading to any platform
- Web UI (command line is sufficient)
- Background music
- Animated illustrations
